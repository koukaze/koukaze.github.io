# Peijing Pang

Academic homepage: [koukaze.github.io](https://koukaze.github.io/).

A static site presenting research experience, code projects and education. Styles and JavaScript are served directly; no build step is required.

## Local preview

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`. Edit `index.html` for project descriptions and links; `scene.css`, `scene.js` and `scroll-navigation.js` control section navigation, and `contact.css` styles the contact section.

GitHub Pages serves the root of the `main` branch.
